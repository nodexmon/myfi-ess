# MyFi ESS — Planning and Governance

MyFi ESS is a proposed Employee Self-Service application. This repository stores its approved planning documents, architecture, workflows, security design, testing plan, and agent development governance.

**Current status:** Documentation and planning only. No application source code, running infrastructure, or deployment is authorized by this documentation commit.

The authoritative planning package includes `DOCUMENT_INDEX.md`, `TECHNICAL_READINESS.md`, and the documents under `docs/`.
